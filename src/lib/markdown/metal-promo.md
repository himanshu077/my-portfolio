# Metal Promo Order Portal

**Customer Order Management & Proof Review for Metal Promo (Precision Coins)**

The portal manages orders submitted through the company's price-quote forms at [metalpromo.com/price-quote](https://metalpromo.com/price-quote/) and [customchallengecoins.net/pricequote](https://customchallengecoins.net/pricequote/).

---

## What it does

- Integrates with several Zoho services (**CRM, Books, Creator, WorkDrive**) so customers get one place for everything about an order
- Customers **manage orders, review proofs, submit feedback and complete order requests**
- Streamlines the customer journey from the first price quote through proof approval to final delivery

## Tech Stack

Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS · Zoho CRM / Books / Creator / WorkDrive · Chart.js
